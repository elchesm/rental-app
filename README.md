# 🏠 동거동락 — 임대관리앱

엄마와 나, 둘이 함께 쓰는 원룸 임대관리 앱입니다.
단일 HTML 파일 하나로 동작하며, 설치가 필요 없습니다.

## 사용 방법

1. 스마트폰 브라우저(Chrome, Safari)로 접속: **https://elchesm.github.io/rental-app/**
2. 이메일과 비밀번호로 로그인 (가족 공용 계정)
3. 홈 화면에 추가(Add to Home Screen)하면 앱처럼 사용 가능

> ⚠️ 예전 파일 `rent_app.html`(4자리 PIN 방식)은 더 이상 사용하지 않습니다.
> 접속하면 자동으로 새 앱으로 이동합니다.

## 주요 기능

- 건물 · 호실 · 세입자 · 수납 · 지출 관리
- 🔥 가족 공유 실시간 동기화 (Firebase Firestore)
- ☁️ 영수증 사진 클라우드 공유 (Firebase Storage)
- 📋 변경 이력 & 롤백 (스냅샷 300개) + 📜 전체 기록 영구 보관
- 🛡️ 데이터 보호: 삭제 동기화(묘비), 빈 데이터 덮어쓰기 차단, 동기화 끊김 경고 배너
- 🖨️ 연도별 세금보고서 출력 (종합소득세 신고 자료 / 세무사 제출용)
- 세입자 퇴거일 관리, 연세 ↔ 월세 계약 전환

## 구조

- **앱 본체:** `index.html` (단일 파일)
- **호스팅:** GitHub Pages (main 브랜치)
- **백엔드:** Firebase — Firestore(데이터), Authentication(로그인), Storage(사진/서류)

## 배포 방법

1. GitHub에서 `index.html` 교체 (Add file → Upload files → Commit)
2. 업로드 후 파일명이 `index_1.html` 등으로 바뀌었으면 반드시 `index.html`로 이름 변경
3. 1~2분 뒤 앱 새로고침 → 설정 맨 아래 정보란의 **버전 표시**로 적용 확인
