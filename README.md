# 🏠 동거동락 — 임대관리앱

엄마와 나, 둘이 함께 쓰는 원룸 임대관리 앱입니다.  
단일 HTML 파일 하나로 동작하며, 설치가 필요 없습니다.

---

## 사용 방법

1. `rent_app.html` 파일을 스마트폰 브라우저(Chrome, Safari)로 열기
2. 홈 화면에 추가(Add to Home Screen)하면 앱처럼 사용 가능

---

## 주요 기능

| 탭 | 기능 |
|---|---|
| 🏠 대시보드 | 이번달 수납 현황, 미납·만료·공실 알림 |
| 👥 세입자 | 현세입자/과거세입자 관리, 계약 갱신 |
| 💰 수납 | 연간 12개월 수납 그리드, 월세/연세 처리 |
| 📄 지출 | 건물별 지출 기록, 영수증 사진 첨부 |
| ⚙️ 설정 | Firebase 동기화, JSON/CSV 내보내기 |

### 특수 기능
- **📱 SMS 파싱**: 은행 입금 문자를 붙여넣으면 자동으로 수납 처리
- **☁️ 실시간 동기화**: Firebase를 통해 두 기기(엄마 폰 ↔ 내 폰) 자동 동기화
- **🔍 검색**: 세입자, 수납, 지출 페이지 모두 이름/항목 검색 가능

---

## 데이터 저장 구조

```
appData
├── buildings  — 건물 정보
├── rooms      — 호실 정보
├── tenants    — 세입자 정보
├── rents      — 수납 기록
└── expenses   — 지출 기록
```

- **로컬**: 브라우저 localStorage에 우선 저장
- **클라우드**: Firebase Firestore 실시간 동기화 (자동)
- **백업**: 설정 탭에서 JSON / CSV 내보내기

---

## ⚠️ 보안 주의사항

- 이 저장소는 **반드시 비공개(Private)**로 유지하세요
- `rent_app.html` 내부에 Firebase API 키가 포함되어 있습니다
- 공개(Public) 저장소로 전환하면 Firebase 프로젝트가 노출될 수 있습니다
- Firebase Console에서 **보안 규칙(Security Rules)**을 설정해두는 것을 권장합니다
- 세입자 주민등록번호 등 개인정보가 저장될 수 있으니 기기 분실에 주의하세요

## Firebase 설정

Firebase를 처음 설정하거나 변경하려면 `rent_app.html` 파일 내 `FIREBASE_CONFIG` 값을 수정하세요.

```javascript
const FIREBASE_CONFIG = {
    apiKey: "...",
    authDomain: "...",
    projectId: "...",
    ...
};
```

[Firebase Console](https://console.firebase.google.com)에서 프로젝트 설정 > 앱 추가 > 웹 앱에서 값을 복사할 수 있습니다.
